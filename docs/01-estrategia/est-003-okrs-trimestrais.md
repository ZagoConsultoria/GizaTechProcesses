# POP: Fechamento e Definição de OKRs

!!! info "Ficha Técnica"
    **CÓD:** EST-003 | **Data:** 17/12/2025 | **Revisão:** 00  
    **Processo Pai:** Gestão de Desempenho e Metas

## 1. O que é
Este documento define o padrão para o ciclo trimestral de **Objectives and Key Results (OKRs)** na Zago/Claraval.
Ele abrange o ritual de encerramento (grading) do trimestre atual e a definição (planning) dos objetivos para o próximo trimestre.

## 2. Objetivo
Garantir foco, alinhamento e engajamento de todos os times em torno de metas comuns e mensuráveis.

As principais finalidades são:

- **Foco:** Evitar a dispersão de esforços em atividades que não movem o ponteiro do negócio.
- **Alinhamento:** Conectar o trabalho diário da operação com a estratégia anual da empresa.
- **Transparência:** Deixar claro para todos o que é prioridade e o que não é.

## 3. Responsabilidades

| Quem faz? | O que faz? |
| :--- | :--- |
| **Diretoria** | • Define as Diretrizes Estratégicas (Anuais/Trimestrais) da empresa. |
| **Heads / Líderes** | • Desdobram a estratégia em OKRs Táticos para suas áreas. |
| **Times (Squads)** | • Definem os OKRs Operacionais (Bottom-up) alinhados com a tática. |

## 4. Diretrizes Gerais
Para garantir a qualidade dos OKRs:

* [ ] **Mensurabilidade:** Todo Key Result (KR) deve ter um número. Se não tem número, não é KR.
* [ ] **Ambição:** Os objetivos devem ser desafiadores (Moonshots), onde atingir 70% já é considerado sucesso.
* [ ] **Menos é Mais:** Máximo de 3 a 5 Objetivos por time, com 3 a 5 KRs cada. Foco é essencial.

# Anexo: Instrução de Trabalho (IT)

!!! abstract "IT-EST-03 - Ritual Trimestral de OKRs"
    **Periodicidade:** Trimestral (Última semana de Mar, Jun, Set, Dez)  
    **Ferramentas:** Planilha de OKRs / Software de Gestão (ex: Qulture, ClickUp)

### Etapa 1 — Fechamento do Trimestre (Grading)
- [ ] Coletar os resultados finais de cada KR do trimestre que está acabando.
- [ ] Atribuir a nota final (Score):
    - 🟢 **0.7 a 1.0:** Sucesso (Atingiu ou superou).
    - 🟡 **0.4 a 0.6:** Progresso, mas não atingiu.
    - 🔴 **0.0 a 0.3:** Falha (Rever estratégia).
- [ ] Realizar retrospectiva rápida: O que impediu o atingimento? O que funcionou bem?

### Etapa 2 — Definição do Novo Trimestre (Planning)
- [ ] **Top-down:** Diretoria apresenta as prioridades macro para o próximo tri.
- [ ] **Draft (Rascunho):** Times se reúnem para propor seus objetivos baseados na estratégia.
- [ ] **Negociação:** Líderes validam se os objetivos dos times conversam entre si (dependências cruzadas).
    > **Nota:** Garantir que Time de Produto e Time de Engenharia não tenham metas conflitantes.

### Etapa 3 — Publicação e Comunicação
- [ ] Cadastrar os novos OKRs na ferramenta oficial.
- [ ] Realizar reunião geral (All Hands) para apresentar os objetivos globais.
- [ ] Definir o calendário de **Check-ins** (acompanhamento quinzenal ou mensal) para garantir que a meta não seja esquecida.
