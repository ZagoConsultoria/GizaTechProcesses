# POP: Revisão Estratégica de Portfólio

!!! info "Ficha Técnica"
    **CÓD:** EST-002 | **Data:** 17/12/2025 | **Revisão:** 00  
    **Processo Pai:** Governança de Produto

## 1. O que é
Este documento define o ritual mensal de análise de desempenho de todos os produtos ativos (Internos e Externos) da Zago/Claraval.
O foco é validar se os produtos continuam entregando valor e se estão alinhados com a visão de longo prazo da empresa.

## 2. Objetivo
Garantir governança sobre o ciclo de vida dos produtos, permitindo tomadas de decisão rápidas sobre priorização, investimento ou descontinuidade.

As principais finalidades são:

* **Alinhamento:** Garantir que o esforço de Engenharia está focado no que traz retorno.
* **Correção de Rota:** Identificar produtos com baixa adoção ou ROI negativo antes que consumam mais recursos.
* **Visibilidade:** Manter a diretoria informada sobre o progresso macro (sem entrar no microgerenciamento de tarefas).

## 3. Responsabilidades

| Quem faz? | O que faz? |
| :--- | :--- |
| **Head de Produto** | • Consolida os indicadores (KPIs) e prepara a apresentação executiva.<br>• Propõe ajustes no Roadmap. |
| **Diretoria** | • Valida as propostas de mudança de prioridade.<br>• Aprova ou veta novos investimentos. |
| **Tech Lead** | • Fornece visão sobre viabilidade técnica e débitos técnicos críticos que impactam o negócio. |

## 4. Diretrizes Gerais
Para garantir a eficácia da reunião:

* [ ] **Decisões baseadas em dados:** Nenhuma mudança de rota deve ser feita baseada apenas em "feeling" (trazer números de uso, receita ou satisfação).
* [ ] **Foco no Resultado:** A reunião não é para discutir *features* específicas, mas sim o impacto delas no negócio.
* [ ] **Transparência Radical:** Problemas críticos e riscos (ex: churn, bugs bloqueantes) devem ser expostos claramente, sem suavização.

# Anexo: Instrução de Trabalho (IT)

!!! abstract "IT-EST-02 - Ritual de Revisão de Portfólio"
    **Periodicidade:** Mensal (Toda última Quinta-feira)  
    **Ferramentas:** Apresentação Executiva (Slide), Dashboard de Métricas, Roadmap Macro.

### Etapa 1 — Preparação (Semana anterior à reunião)
- [ ] Coletar dados de performance do mês (Usuários Ativos, Churn, Receita/Economia Gerada).
- [ ] Atualizar o status dos grandes épicos em andamento ( % concluído, previsão de entrega).
- [ ] Identificar riscos ou impedimentos que precisam de apoio da Diretoria.
- [ ] Enviar o material de leitura prévia (Pre-read) até 24h antes da agenda.

### Etapa 2 — Execução (A Reunião)
- [ ] **Visão Geral:** Apresentar o semáforo dos produtos (Verde/Amarelo/Vermelho).
- [ ] **Deep Dive:** Aprofundar apenas nos produtos com status "Vermelho" ou que requerem decisão estratégica.
- [ ] **Roadmap:** Revisar as prioridades para o próximo mês.
    > **Nota:** Se houver solicitação de "pastel" (demanda urgente não planejada), avaliar o impacto no roadmap atual (o que vai cair para isso entrar?).

### Etapa 3 — Saída e Comunicação
- [ ] Registrar as decisões tomadas em ata.
- [ ] Atualizar o Roadmap Oficial conforme as mudanças aprovadas.
- [ ] Comunicar os times (Engenharia e Operações) sobre alterações de prioridade na próxima Daily/Planning.
