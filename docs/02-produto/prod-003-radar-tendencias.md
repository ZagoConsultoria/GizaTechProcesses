# POP: Priorização de Tendências e Radar

!!! info "Ficha Técnica"
    **CÓD:** PROD-003 | **Data:** 17/12/2025 | **Revisão:** 00  
    **Processo Pai:** Gestão de Inovação e Estratégia

## 1. O que é
Este documento define o ritual semanal de **análise e priorização do Radar de Inovação**.
O "Radar" é o repositório onde concentramos ideias vindas de: análise de concorrentes (benchmarking), novas tecnologias (IA, APIs), sugestões internas e tendências de mercado.

## 2. Objetivo
Filtrar o "ruído" do "sinal", garantindo que a Zago/Giza invista tempo explorando apenas inovações que tragam vantagem competitiva real ou resolvam dores latentes.

As principais finalidades são:

* **Competitividade:** Não ficar para trás em relação aos concorrentes diretos.
* **Alimentação do Funil:** Garantir que o processo de Discovery (PROD-001) sempre tenha pautas relevantes.
* **Foco:** Dizer "não" rapidamente para ideias que são apenas "Hype" (moda passageira) e não trazem valor ao negócio.

## 3. Responsabilidades

| Quem faz? | O que faz? |
| :--- | :--- |
| **Product Manager** | • Traz insights de mercado e concorrentes.<br>• Facilita a priorização baseada em valor de negócio. |
| **Tech Lead** | • Avalia a complexidade e maturidade das tecnologias propostas (Ex: "Essa IA ainda é muito cara/instável"). |
| **UX Designer** | • Traz referências de interface e experiência de outros produtos. |

## 4. Diretrizes Gerais
Para uma priorização eficaz:

* [ ] **Conexão com OKRs:** A tendência ajuda a bater a meta do trimestre? Se não, vai para o "Banco de Ideias" (Icebox).
* [ ] **Problema > Solução:** Não adotar uma tecnologia só porque é legal. Qual problema do cliente ela resolve?
* [ ] **Benchmarking Ético:** Analisar concorrentes é vital, mas copiar sem entender o contexto é erro.

# Anexo: Instrução de Trabalho (IT)

!!! abstract "IT-PROD-03 - Ritual do Radar (Terça-feira)"
    **Periodicidade:** Semanal (Terça-feira)  
    **Ferramentas:** Quadro de Radar (Miro/Notion), Feedly/Newsletters, Logs de Concorrentes.

### Etapa 1 — Coleta de Sinais (Contínuo)
- [ ] Monitorar atualizações de concorrentes (Release Notes, Redes Sociais).
- [ ] Acompanhar notícias do setor e tecnologias emergentes.
- [ ] Centralizar sugestões do time interno (Vendas/Suporte) no "Inbox do Radar".

### Etapa 2 — Reunião de Priorização (Terça-feira)
- [ ] **Revisão do Inbox:** Ler as novas ideias que entraram na semana.
- [ ] **Classificação Rápida:**
    - 🗑️ **Descartar:** Não faz sentido para o negócio.
    - 🧊 **Congelar:** Interessante, mas não agora (Icebox).
    - 🔭 **Investigar:** Merece um estudo mais aprofundado (Discovery).
- [ ] **Matriz de Impacto x Esforço (T-shirt Sizing):** Para os itens "Investigar", estimar rapidamente o tamanho da oportunidade.

### Etapa 3 — Saída (Output)
- [ ] Os itens aprovados como "Investigar" tornam-se pauta para o **Discovery da próxima semana (PROD-001)**.
- [ ] Atualizar o status no Roadmap de Inovação.
- [ ] Comunicar ao time se houver alguma mudança brusca de direção devido a um movimento de concorrente.
