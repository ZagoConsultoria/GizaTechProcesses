# Política de segurança

## Como reportar uma vulnerabilidade
Não abra issue pública. Comunique diretamente a equipe de tecnologia responsável por este projeto, com a descrição, os passos para reproduzir e o impacto.

## O que fazemos
- Segredos ficam fora do repositório e são girados quando há suspeita de vazamento.
- Dependências monitoradas por alertas do GitHub.
- Mudanças passam por Pull Request e revisão.
